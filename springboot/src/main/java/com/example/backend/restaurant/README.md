# restaurant

사업자 신청·프로필과 음식점·메뉴·태그·소식의 생명주기를 소유하는 모듈입니다.

## 현재 상태

현재는 대부분 `package-info.java`로 책임과 구현 위치를 확정한 설계 골격입니다.
빈 패키지는 미사용 폴더가 아니라 후속 기능을 위한 의도적인 구조입니다.

## 패키지 책임

- `controller/`: 사업자 신청과 사업자용 음식점 관리 API
- `domain/`: 사업자·음식점 핵심 엔티티와 상태 타입
- `repository/`: 사업자·음식점 영속성 접근
- `dto/`: 신청 및 음식점 관리 요청·응답
- `service/`: 신청, 권한 연결, 음식점 등록·수정·비활성화
- `policy/`: 신청 가능 여부와 음식점 소유권
- `mapper/`: 도메인과 API DTO 변환
- `event/`: 신청 처리·음식점 상태 변경 후속 이벤트
- `integration/`: 공공데이터와 이미지 저장소 연동
- `menusubmission/`: 사용자 메뉴 제보의 독립된 하위 영역

지도·게시판·추천 모듈은 음식점 데이터를 복제하지 않고 이 모듈의 조회 모델을 사용해야 합니다.
